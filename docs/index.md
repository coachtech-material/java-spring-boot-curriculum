## この教材で身につくこと

| 領域 | 到達点 |
|---|---|
| **言語の土台** | 静的型付けと本格的なオブジェクト指向（継承・インターフェース・ポリモーフィズム・ジェネリクス）を理解し、設計・読解できる |
| **現代的な Java** | record・enum・Optional・ラムダ・Stream で、不変データ・null 安全・宣言的なコレクション操作を簡潔に書ける |
| **Spring Boot** | DI コンテナ・アノテーション駆動・オートコンフィギュレーションの「なぜ動くのか」を自分の言葉で説明できる |
| **REST API** | Spring MVC で API を設計・実装し、Spring Data JPA でデータアクセス層（リレーション・トランザクション・N+1 対策）を組める |
| **実務品質** | Spring Security で認証・認可を実装し、JUnit / Mockito / MockMvc でテストを書ける |

最終的に、**1つの REST API アプリケーションをゼロから設計・実装・テストできる** ことをゴールとします。

## 対象読者

Laravel（PHP）で Web アプリケーションを一通り開発した経験を持ち、これから Java / Spring Boot を学ぶ方を対象としています。Java は未経験でも問題ありません。すでに持っている「Web 開発の考え方」を最大の資産として、Laravel との対比を背骨に Java の世界へ橋渡しします。
